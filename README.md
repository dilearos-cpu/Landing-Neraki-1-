# Landing-Neraki-1-

Repositorio para landings y herramientas de conversión de **Diego Arango**.

## Landing Bonus (WooCommerce)

Plugin WordPress/WooCommerce que replica las herramientas de conversión de las landing Caletzza (Shopify).

Ver documentación completa en [`landing-bonus-wc/`](./landing-bonus-wc/).

### Inicio rápido

```bash
# Copiar plugin a WordPress
cp -r landing-bonus-wc/landing-bonus /ruta/a/wp-content/plugins/
```

Luego activar en **Plugins → Landing Bonus** y configurar en **WooCommerce → Landing Bonus**.
