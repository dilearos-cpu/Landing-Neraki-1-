## Diego Arango - Social Proof Boost (WooCommerce)

Plugin de notificaciones emergentes de prueba social para WooCommerce.

### Instalación

1. Copia la carpeta `diego-arango-social-proof` en `wp-content/plugins/`
2. Activa el plugin en WordPress (requiere WooCommerce)
3. Ve a **WooCommerce → Social Proof Boost**

### Uso

Crea un shortcode en el panel de admin y pégalo en cualquier página:

```
[dasp_social_proof id="dasp_xxxxxxxx"]
```

Ejemplo de notificación:

> **Juanito** ha comprado un **pack de bodys x4** hace 1 minuto en **Bogotá**

### Características

- 20 ciudades principales de Colombia
- Nombres y tiempos aleatorios
- Personalización de pack, prefijo y unidades
- Shortcodes para páginas puntuales
- Panel de administración completo
