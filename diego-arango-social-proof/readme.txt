Notificaciones emergentes de prueba social para WooCommerce. Aumenta la conversión mostrando compras simuladas aleatorias en ciudades de Colombia.

== Description ==

**Diego Arango - Social Proof Boost** es un plugin de WooCommerce que muestra notificaciones emergentes tipo "Juanito ha comprado un pack de bodys x4 hace 1 minuto en Bogotá" mientras los visitantes navegan tu tienda.

= Características =

* Notificaciones emergentes con animación suave
* Nombres y ciudades aleatorias de Colombia (20 ciudades principales)
* Shortcodes para usar en páginas específicas
* Panel de administración en WooCommerce
* Personalización del nombre del pack, prefijo y unidades
* Control de intervalos, duración y posición del popup

= Uso =

1. Instala y activa el plugin (requiere WooCommerce)
2. Ve a **WooCommerce → Social Proof Boost**
3. Crea un shortcode con el pack y unidades deseados
4. Copia el shortcode y pégalo en tu página de producto o landing

Ejemplo de shortcode:

`[dasp_social_proof id="dasp_abc12345"]`

== Installation ==

1. Sube la carpeta `diego-arango-social-proof` a `/wp-content/plugins/`
2. Activa el plugin desde el menú 'Plugins' en WordPress
3. Asegúrate de tener WooCommerce instalado y activo
4. Configura tus shortcodes en WooCommerce → Social Proof Boost

== Frequently Asked Questions ==

= ¿Necesito WooCommerce? =

Sí, este plugin requiere WooCommerce activo.

= ¿Las compras son reales? =

No. Son notificaciones simuladas de prueba social para aumentar la confianza y conversión.

= ¿Puedo usar varios shortcodes en la misma página? =

Sí, puedes insertar múltiples shortcodes con diferentes configuraciones.
